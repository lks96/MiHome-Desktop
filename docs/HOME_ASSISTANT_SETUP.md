# Home Assistant 联调

## 服务准备

Home Assistant 独立运行，不包含在客户端安装包中。安装适合你 HA 版本的 Xiaomi Miot 集成（需要时先安装 HACS），使用正确账号地区接入米家设备。先在 HA 中验证实体可读取、设备可控制。

在 HA 用户资料的安全页面创建长期访问令牌。只在客户端设置页的令牌输入框填写，禁止提交到 Git、放进 SQLite 或发送到聊天。

## 客户端连接

1. 在 Windows 桌面客户端进入系统设置。
2. 输入完整实例地址，例如局域网 HTTP 地址或 HTTPS 反向代理地址；可以保留部署子路径。不能在 URL 中包含用户名、密码、查询参数或片段。
3. 填写长期访问令牌，点击“测试连接”。此步骤仅验证 REST API，不保存配置或代表 WebSocket 已连接。
4. 点击“保存并连接”。Rust 再次验证 API，随后写入 Windows Credential Manager，并在 SQLite 中保存独立凭据引用。保存后清空表单令牌。
5. 查看“正在连接 / 正在认证 / 已连接”状态。只有完成 WebSocket 认证、事件订阅和实体快照加载才显示“已连接”。
6. 在设备中心查看真实 HA 实体。一个物理设备可能对应多个实体；当前已提供 light/switch/climate/fan 的部分按能力控制；详情见设备管理说明。

连接配置与凭据不回显令牌。修改地址需要重新输入令牌；已保存配置可以直接重新连接。

## 实时同步

使用 HA WebSocket 的 `state_changed` 事件作为兼容订阅路径。先建立订阅，再加载快照，并按时间戳避免较早事件覆盖较新状态。实体状态保存在 Rust 内存，SQLite 不复制 HA 实体状态。

断线后使用 1、2、5、10、最长 30 秒（含随机抖动）的重连等待，重新认证、订阅并加载快照。认证失败停止自动重试，需要更新令牌；手动断开会取消后台任务、清空当前列表。请求超时与自动重连设置在下一次建立连接时应用。断线期间界面将最近快照标记为暂停更新。

TLS 验证始终开启；REST 连接测试不跟随重定向，以免将认证请求交给错误页面。请使用实际 HA API 的基地址。局域网 HTTP 使用明文传输，仅用于可信网络；远程访问应使用 HTTPS 或 VPN。WebSocket 当前使用系统网络的直接 TCP/TLS 路径，部署时须让 HA 地址能从用户 Windows 主机直接访问。

## 验证边界

本地协议测试可验证请求、认证、事件、重连和数据库逻辑，不能证明用户设备或摄像头兼容。Windows Credential Manager、WebView2、真实 HA 和真实摄像头仍需在最终 Windows 环境验收。
