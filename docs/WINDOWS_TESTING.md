# Windows 测试包验收清单

这是验收步骤，不是已经通过的记录。

## 安装与桌面

- 对照 SHA256SUMS.txt 检查文件，安装当前用户 NSIS 包。
- 在 Windows 10 22H2 / Windows 11 x64 中启动，确认 WebView2 可用。
- 调整窗口大小、位置和最大化，退出再启动验证恢复，启动时不应保持隐藏。
- 启用“关闭窗口后留在托盘”，关闭主窗口，再从托盘显示并退出。
- 窗口隐藏时视频停止；恢复后只为当前可见槽位建立会话。
- 切换开机启动，检查 Windows 启动应用状态，实际注销/登录验证。
- 卸载后检查应用没有残留进程，启动注册值已清除。

## HA 与设备

- 错误地址/Token 产生明确错误，正确配置完成 REST 和 WebSocket 认证。
- 退出再启动可读取凭据，不需要在界面回显 Token。
- SQLite 中只应存在凭据引用，不应有访问令牌。
- 至少验证一台真实灯或插座的控制及状态同步。
- 断网/恢复后自动重连；无效令牌不无限重试。
- 搜索、房间、收藏、隐藏/恢复、名称覆盖和排序正常保存。

## 场景

- 真实 HA 场景可以收藏与执行，执行时不重复提交。
- 场景执行失败可见，场景返回成功不应被表述为所有物理设备状态已确认。

## 摄像头

- 补全 CAMERA_COMPATIBILITY.md 的型号、固件、编码与版本记录。
- 区分截图与实时视频，只有收到实际帧才显示播放。
- 使用真实 go2rtc 验证单画面和四宫格，连续播放至少 30 分钟。
- 检查静音、全屏、断流恢复、页面离开和窗口隐藏时的资源释放。
- 单独记录 H.265/HEVC 与 H.264 在目标 WebView2 上的结果。

## 诊断

- 先确认提示再导出，取消保存对话框不创建文件。
- 导出的 JSON 可以解析，不包含 Token、密码、认证 URL、SDP 或数据库内容。
- 导出失败时原有文件不应被不完整内容覆盖。
